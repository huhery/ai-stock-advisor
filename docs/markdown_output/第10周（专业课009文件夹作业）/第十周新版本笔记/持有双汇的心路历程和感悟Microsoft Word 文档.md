持有双汇的心路历程和感悟

在买入双汇之前，一直关注着，也计算了好价格在23.8元附近，在2019年8月2日23.6附近买入了2手，心里很高兴，终于等到好价格了，终于上车了（买过后才发现是我老婆的账户，打新债用的）。

过了个星期天，在2019年8月5日周一一天就大跌了3.85%，心想怎么回事儿？刚买就大跌？怎么这么倒霉？群里边讨论才知道是因为人民币贬值引起的，心里也慌了，早知道等两天不是更好！突然又想到了课程中的知识，没有人能买到最低点，只要在好价格买入就行，在乎那么一点儿成本，根本没有意义，心情马上就不一样了。

周二跌了2.69%，又问了一下老师，人民币贬值会影响多长时间？还能不能按照之前学的下跌5%－10%时，在买一部分降低一下成本？老师也明确的给我说人民币贬值只是暂时的，可以按照课程学的，下跌5%－10%继续投资。老师的话像一针强心剂，给了我信心，于是在2019年8月7日周三，下跌2.4%，大概跌幅达到8%左右，在21.5时又买入3手（这次用的是我自己的账户买的），还预留了一部分资金，等到在下跌5%-10%左右时在买入一部分。结果买入后就有小幅上涨，就没有再加仓。

后来在24－26元之间，小幅震动了好久，最终还是没有忍住，把老婆的那个账户的2手卖了（当时想的是专门用来打新债的不参与股市，老婆是个保守的人，如果用我自己的我会一直持有），当时收益10%左右。心里想等降下来点儿用我自己的账户补仓，结果卖出后就再也没有降下来，不过还好我自己的账户的3手，一直持有到现在，收益达到了48.3%，心里还是非常高兴的。

虽然现在收益很高，但是又会有一种想法，就是后悔当初买少了，想想这也是正常的，这就是贪念，还是要平常心对待，不能贪多，要按照课程的要求买入卖出。还会有很多负面小消息，在双汇27元左右时，同事说双汇要跌了，猪肉价格不可能一直涨下去……，庆幸的是，最终还是拿住了。当然还会有，当收益达到30%以上时，就会经常纠结要不要卖出，卖了等降了了再买入，后还是打消了这种念头，我们是实现财务自由的，不是让自己纠结的，这样纠结，这样累，即使赚到了钱，也永远实现不了财务自由，因为本身自己就没有自由。

因为自己分析过双汇，知道双汇是好公司，而且是在好价格买进的，根本不担心它下跌，即使下跌，也会给我更好地投资机会；即使不跌，一直小幅震动，我也能有股息分红收益；当然上涨了，有增值收益我会更高兴。这些都是在微淼学到的。

另外，还要多看以前的实践课，增强内功，好公司好股票长期持有，时刻要明白我们是做投资的，而不是赚差价的；我们是要实现财务自由的，而不是赌徒。

非常感谢微淼商学院，让我不断成长，让我又重新找到了方向，人生又有了奋斗目标，我会向着这个目标不断努力，争取早日实现财务自由。

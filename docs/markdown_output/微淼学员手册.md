7.  微淼的教学模式

线上视频课+线上测试+实战操作+案例分析+小组讨论+毕业后持续指导

美国国家训练实验室的研究成果显示不同的学习方式产生的学习效果迥

异，主动学习方式更有助于学习者有效地掌握学习内容，达到事半功倍的效

果，其中教别人（90%）、实践（90%）、模拟演练（70%）、小组讨论

（50%）这四种学习方式的效果最好，如上图金字塔所示。所以实践课以这四

种学习方式为主。

线上视频课（留存率 25%）：近 170 个 5 分钟左右的短视频，方便学员学

习和复习。

线上测试（留存率 70%）：每个短视频后有 1 道测试题；每个章节结束

后，有 10 道测试题；每周实践课结束前也有相应的测试题。不同形式的测试可

以帮助学员吸收掌握课程精华。

七、请假

1.  学员仅有 4 次请事假的机会。需至少提前一天向指导老师请假。因没有准假

导致缺考的，个人当次考试分数为 0 且不能补考。学员提前请假获批的，可以在

未来 5 天内补考。补考分数计入个人分数。

2.  学员可以请病假。自己、家人生病的可以请病假。不需要提前请。当天和指导

老师请假即可，但事后需要提供自己或家人的病历证明。不能提供病历证明的，

按旷课处理。个人当次考试分数为 0 且不能补考。能提供病历证明的，未来 5 天

内可以补考。补考分数计入个人分数。

3.  孕妇休产假，可以办理休学。孕妇办理休学的，个人分数暂不统计。因休学需

要调班的，可以安排调班。

4.  学员发生重疾、重大意外事故的，可以办理休学。个人分数暂不统计。因休学

需要调班的，可以安排调班。
